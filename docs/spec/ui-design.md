# 笔记工作区界面设计规格

笔记库侧栏省去重复的新建笔记和管理分类入口；顶部搜索支持标题、正文、标签，不再单列标签输入框。卡片使用最多 1,600 字符的摘要，复用正文 Markdown、KaTeX、代码高亮及表格渲染。进入目录滚动区域附近后，在空闲时间提交给本地 Worker；不支持 Worker 时回退。渲染结果缓存最多 48 项、合计 256,000 UTF-16 单位（键与 HTML 字符数），过大结果不缓存。截断的末尾块公式不展示源码。

整张卡片保持单一打开操作，内部 Markdown 链接使用样式化文本、任务使用非交互标记，原始 HTML 不执行。图片沿用懒加载并限制显示高度。网格预览固定 204px，列表保持紧凑；尚未渲染时使用固定大小占位，避免解析过程明显改变列表滚动位置。回收站和笔记原文不因预览被改写。

Chrome（Windows 默认检测常见安装路径，或通过 `DSH_TEST_CHROME` 指定）；其他环境先使用 Playwright 安装 Chromium。测试不启动替代服务器，不连接用户资料，也不自动安装插件。

[Playwright 用例](../../tests/browser/workspace.spec.mjs) 在隔离 origin 中加载实际预构建 Client，使用真实 React 渲染；HTTP 请求交给实际 Host 服务的内存适配器。覆盖深浅主题、网格/列表、分区/侧栏分类筛选、编辑保存、专注模式草稿保留、预览与 CRLF/折行源码目录跳转、历史与统一设置（外观、存储位置）弹窗、手机返回与共写切换、词法检索、附件原始字节及引用插入、英文与无模糊降级。

额外使用 1919×1033 窗口、280px 宿主侧栏与 40px 顶栏的隔离外壳复现日常使用比例，验证目录默认关闭、打开笔记后侧栏固定显示目录且宽度超过 240px、正文占可用编辑区超过 90%，以及宽/窄编辑区的目录开关和 Escape。该回归专门防止只在无宿主外壳的展示尺寸中验证布局。

截图输出至 `.build/ui/`，失败 trace 位于 `.build/browser-results/`。截图使用显式种子笔记，不是用户真实资料。该验收验证真实浏览器中的插件 UI；原生 DSH 会话与宿主外壳在 fixture 中以适配器表示，因此不能声称已验证当前已安装插件或所有宿主交互。
