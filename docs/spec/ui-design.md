# 笔记工作区界面设计规格

Chrome（Windows 默认检测常见安装路径，或通过 `DSH_TEST_CHROME` 指定）；其他环境先使用 Playwright 安装 Chromium。测试不启动替代服务器，不连接用户资料，也不自动安装插件。

[Playwright 用例](../../tests/browser/workspace.spec.mjs) 在隔离 origin 中加载实际预构建 Client，使用真实 React 渲染；HTTP 请求交给实际 Host 服务的内存适配器。覆盖深浅主题、网格/列表、分区/本页导航/快速筛选、编辑保存、专注模式草稿保留、预览与 CRLF/折行源码目录跳转、历史/存储弹窗、手机返回与共写切换、词法检索、附件原始字节及引用插入、英文与无模糊降级。

额外使用 1919×1033 窗口、280px 宿主侧栏与 40px 顶栏的隔离外壳复现日常使用比例，验证目录默认关闭、实际笔记条目宽度超过 240px、正文占可用编辑区超过 90%、分类切换不关闭当前文档，以及宽/窄编辑区的目录开关和 Escape。该回归专门防止只在无宿主外壳的展示尺寸中验证布局。

截图输出至 `.build/ui/`，失败 trace 位于 `.build/browser-results/`。截图使用显式种子笔记，不是用户真实资料。该验收验证真实浏览器中的插件 UI；原生 DSH 会话与宿主外壳在 fixture 中以适配器表示，因此不能声称已验证当前已安装插件或所有宿主交互。
