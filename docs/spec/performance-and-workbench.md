# 写作工作区与性能规格

## 参考与适用边界

参考 [Quiet.md](https://github.com/s1dashu/quiet-md/tree/57884b9c8e49d22effe18885c6d717d8acb67278) 的可见区、增量更新、命令、派生目录与布局原则。其实现是 Rust + GPUI 原生界面，主要文档模型为 DocxXML。本项目继续使用 DSH Web 插件、Markdown 原文、现有 Host 存储与共写，不移植 GPUI，也不复制其品牌或商业图标。

参考依据包括 [编辑区可见行与缓存](https://github.com/s1dashu/quiet-md/blob/57884b9c8e49d22effe18885c6d717d8acb67278/src/editor/render.rs#L1026-L1106)、[按 pane 宽度布局目录](https://github.com/s1dashu/quiet-md/blob/57884b9c8e49d22effe18885c6d717d8acb67278/src/editor/catalogue.rs#L14-L76)、[树移动的历史事务](https://github.com/s1dashu/quiet-md/blob/57884b9c8e49d22effe18885c6d717d8acb67278/src/file_history.rs#L33-L154)。CM6、IndexedDB 和 Worker 是本项目选择的 Web 实现。

## 编辑与原文

正文使用 CodeMirror 6 的事务、增量解析和可见区 DOM。组件不会在普通受控值回传时重建 EditorView 或重置撤销历史；真正远端全文替换保留视图实例，并清除旧文档的本地撤销历史。

CodeMirror 内部行分隔符为 LF；原文桥接使用带位置增量的换行索引，转换原始 UTF-16 与内部位置。编辑只修改实际变更范围，保留其他 CRLF、LF、CR、Unicode 和空白。撤销/重做的额外状态恢复原始分隔符，不将整篇文稿统一换行。每次局部输入不扫描全文或移动所有后续行的位置数组。

任务复选框和附件引用插入通过精确原文范围提交本地事务，保留与正文输入连续的撤销历史；不把这些界面操作误判为远端全文替换。

输入法组合期间不执行格式命令、补全替换或外部文稿同步；组合结束再校验外部更新。浏览器自动化中的合成组合事件只证明事件保护，不能替代真实操作系统输入法验收。

## 草稿持久化

浏览器草稿先进入内存索引，约 30ms 合并写入 IndexedDB。输入路径使用 opaque 版本 token，不逐键对整篇正文执行 JSON 序列化和 localStorage 写入。records/latest 读取内存；列表仅在新增、删除、标题、初始化或错误变化时收到索引通知。

`cachePending` 表示本机事务尚未提交；只有事务 complete 或服务器确认后才可显示 durable。事务失败保留精确内存内容，可重试；关闭前未提交数据继续触发提示。不能宣称最后一笔异步事务在页面被强制关闭时必然完成。

- 首次打开笔记等待 `noteCache.ready`，避免恢复尚未读取时创建新编辑会话。
- 保留旧草稿键与读取协议；旧副本只在安全写入及原 raw 校验后清理。
- 每个 note/writer 独立，异步状态按 key/raw/generation 校验。事务内进行条件删除，迟到旧提交不能覆盖或复活已保存草稿，也不能删除新 writer 的内容。
- IndexedDB 无法打开时可以回退旧本机缓存，但必须提示之前的草稿可能尚未完整读取；读取失败不得静默显示空恢复结果。
- 草稿按钮打开前按 key 重新获取最新记录，不能恢复列表曾渲染的旧正文快照。
- 缓存通知订阅跟随会话 start/pause/stop/abandon，关闭笔记后不得由全局监听器继续保留整个旧正文。恢复订阅时同步暂停期间的事务结果。

Host 资料格式与笔记 revision 不因浏览器缓存优化改变。自动保存、历史快照、冲突保护和原生会话继续使用原接口。

## 渲染、可视化与目录

编辑、预览、分屏三种视图共享同一原文。格式工具栏、常用 Markdown 快捷键和行首 `/` 菜单生成可编辑的 Markdown。分屏预览保留表格、公式、代码、图片及任务列表；过期画面在新结果提交前保留，但任务修改按钮禁用。

小文档直接渲染，较大文档通过内嵌本地 Blob Worker 解析。一次解析输出平衡的内容块、标题和任务偏移，保留链接引用、列表、编号、表格和数学语义。长列表按完整列表项分批；极端单个巨大表格、代码块或嵌套项仍作为完整内容块处理，其内部尚未虚拟化。

预览用测量缓存、上下占位与可见区内容块限制 DOM；标题跳转可强制挂载远距离内容，再滚动和聚焦真实标题。后续实时更新约 180ms 合并；队列与缓存按 consumer/kind 隔离，跨消费者公平调度，避免历史预览取消主文预览。卸载取消所属排队请求。Worker 失败有安全回退，不能假设所有宿主都允许 Worker。

文档目录只在打开时订阅和生成，关闭时不继续整篇解析。它从同一解析器派生标题，保留唯一编号与原文位置；长目录使用有界行窗口，折叠只改变视图。异步旧结果不能覆盖当前内容，解析进行中不能用旧偏移跳转。

分类/文件目录在现有左侧区域与笔记列表切换，保持正常编辑两栏。展开时懒取直接归属的笔记元数据，不拉正文；32px 行窗口和占位限制实际挂载节点。支持分类/文件拖动、内联新增改名与分类移动撤销。撤销同样检查已确认的树 revision，外部变更后不重放逆操作。手机目录切换通过布局状态保留编辑器实例。

## 性能验证方法

使用 [浏览器基准](../../tests/performance/workspace.bench.mjs)，冻结优化前 Client/Host，再用同一 Chrome、1440×1000、DPR 1、相同 100k/1M 种子文稿和 30 次真实按键对比。数据只保存在隔离内存 Host 和测试浏览器；没有服务器或用户资料写入。

记录按键至 input 后微任务检查点、按键至首个 rAF 的 P50/P95、切换预览到 ready 和布局稳定的耗时、DOM 数量与 longtasks。微任务检查点不是精确 React commit；rAF 不是实际屏幕呈现。单轮样本只用于同条件回归，不作为跨设备 SLA。滚动在边界可能被夹住，不能仅据 rAF 结果宣称完整遍历流畅。

优化前本机百万字符基线：输入检查点 P95 43.6ms、首帧 P95 54.8ms、预览 1929.8ms、页面元素 35,349。Quiet 的 [原生性能报告](https://github.com/s1dashu/quiet-md/blob/57884b9c8e49d22effe18885c6d717d8acb67278/docs/PERFORMANCE.md) 使用不同硬件与应用内 draw 统计，不能作为本项目相同口径的目标或结果。

功能验收覆盖真实键入、原文/撤销、查找与补全、快捷键上下文、目录拖放/撤销、手机保实例导航、真 IndexedDB 离线落盘和刷新恢复，以及主题/高对比/附件/历史/共写回归。截图使用隔离示例；它们不等于当前已登录 DSH GUI 或真实 OS 输入法的完整验收。

## 2026-11-10 最终同机对比

Chrome 146、Windows x64、1440×1000/DPR 1、相同种子与冻结 Host，每种规模 30 次真实按键，串行运行。最终 Client SHA256 为 `e9f3a6b1cb6cf8a8cf123d45c308194b5a327f456aef0bad8034215262745db3`。下面只比较同一 v2 方法重跑的 baseline 与最终产物；上文原始首轮基线保留为历史，不能混作分母。

| 指标（旧版 → 最终版） | 100k 字符 | 1M 字符 |
| --- | --- | --- |
| 输入事件后微任务检查点 P95 | 3.4 → 3.3ms | 51.1 → 6.8ms |
| 按键至首个 rAF P95 | 16.8 → 17.1ms | 68.2 → 16.8ms |
| 预览 ready 并稳定 | 361.3 → 77.9ms | 2120.8 → 262.6ms |
| 预览时页面元素 | 3,909 → 744 | 35,349 → 749 |
| 采样阶段观测到的 ≥50ms 长任务 | 2 → 0 | 8 → 0 |

100k 的帧回调 P95 略升，不能宣传各项全提升；每组仅一次运行，P95 是样本描述。虚拟预览的 132 个内部元素是当前窗口，ready 不是全文 DOM 已挂载。两组各 30 个 trusted 输入、种子、环境、长度、追加后缀和页面 errors=0 均已校验；性能种子使用 LF，混合换行保真由独立测试覆盖。

未压缩 Client 从 1,653,804 增至 3,055,817 bytes（+84.8%），这是引入编辑器与 Worker 的包体权衡；本次没有量化冷网络加载或整体堆内存收益。固定旧 Host 用于隔离前端收益，未覆盖最终 Host 的 Windows 阶段目录重试或真实资料迁移路径。

上表为该次开发机采样的历史摘要，不代表当前版本的测试结果或性能保证。原始临时样本与冻结产物不随仓库分发；复测时需按上述方法重新准备基线，使用相同脚本和环境采样。
