# dsh-knowledge-base 规格索引

本目录描述当前仓库的实现契约、兼容边界与验收方式。适用于下一次 npm 发布的开发分支；已发布的 0.1.0 不会随源码修改而自动更新。包版本仍为 0.1.0，发布前另行确定版本和更新日志。

修改代码时，可先用 [开发入口](../development.md) 定位模块与验证命令；本目录记录具体行为契约。

## 变更规则

- 对外行为改变时，同时修改对应 spec 与能够验证该行为的测试。
- 内部重构必须保持 npm exports、插件 id、存储域、现有资料格式和已保存引用兼容，除非另有明确迁移设计。
- spec 中“当前行为”应与代码一致；“后续设计”不表示已经实现。
- 发现文档和实现冲突时，先确认兼容要求，再同步修正代码、文档和测试，不能只让断言匹配实现。

## 当前范围

提供 Host 本地笔记、附件、历史、目录迁移、词法检索及 DSH 原生会话共写。WebDAV、多设备实时同步、端到端加密、PDF 文本提取/OCR 均未实现；浏览器异步 IndexedDB 草稿已实现，并保留旧本机缓存兼容。浏览器 UI 保留触发式远端刷新，不承诺多人实时协同。
