# 知识库布局工坊

独立的离线 HTML 布局原型，用来讨论整个知识库工作台。它不连接 DSH，不读取笔记资料库，不调用模型，也不修改已安装插件。

## 打开与调整

双击构建生成的 `workbench.html`，建议用 Chrome 或 Edge 打开。无需服务器或安装依赖。

1. 顶部选择「笔记库 / 阅读笔记 / 编辑笔记 / 问题与共创」场景。
2. 在调整模式，点画布上的控件，或者在左侧图层树选择。右侧显示控件名称、稳定 ID 和适用属性。
3. 更改文字、尺寸、内外间距、字号、排列、对齐、可见性。属性在改完后离开输入框时提交。
4. 拖动选中控件右上角的手柄移动；也可以用「所在容器」和「上移 / 下移」准确定位。仅允许同一场景的兼容容器，禁止循环嵌套。
5. 选中面板后拖动右边的细线调整宽度。固定像素、按内容、占满剩余三种尺寸模式可随时切换。
6. 手机画布使用独立的属性覆盖；移动关系和顺序共用。可以清除当前控件的手机覆盖，让它跟随桌面基础值。
7. 在「给实现者的备注」中写下暂时无法用拖拽表达的要求，例如点击后应该出现的内容。

重复数据组件（笔记卡片、来源列表和会话）按组调整，其内部样例元素用于体验。图层树列出了可以独立移动和调整的项目。

## 体验与保存

「体验模式」隐藏设计工具，可以实际选笔记、编辑样例正文、查看来源和体验模拟会话。会话明确是离线演示。体验输入只在当前页面内存中，不是实际资料。

布局和备注自动保存到当前浏览器。浏览器清理存储或换浏览器时，缓存不会跟随。建议重要修改及时使用：

- **导出 JSON**：保存布局与控件备注。下次用「导入布局」恢复，或把文件发给我作为实施依据。
- **保存 HTML**：把当前布局、手机覆盖、备注与原型程序一起保存为新文件，其他浏览器也能离线继续调整。

导入 JSON 上限 1 MiB。版本、节点和属性校验失败时保留现有布局。导入本身也可撤销。

撤销 / 重做保留最多 100 份布局快照。快捷键为 Ctrl/Cmd+Z、Ctrl/Cmd+Shift+Z，Windows 也支持 Ctrl+Y；输入框内部保留浏览器的文字撤销。重置前有确认，重置后仍可撤销。

把调整后的 **HTML 或 JSON** 发回即可，不必逐条口述位置。截图可用于补充标注。布局确认后，再单独改正式插件。

## 从源码构建与验证

在仓库根目录运行：

```powershell
node prototypes/workbench/build.mjs
node --test tests/prototype/model.test.mjs
node --test tests/prototype/browser.check.mjs
```

输出为 `.build/prototypes/workbench.html`，不会运行正式构建。使用仓库现有 esbuild 与 Playwright 开发依赖，不新增第三方依赖。默认无外部资源请求。
