# 原子级布局原型 · 用户设计版

以用户导出的布局为起点制作，输出为独立离线 HTML。`user-design/layout-20261111.json` 是保留的设计基线，也是构建和迁移测试的输入。与它包含完全相同设计状态的 HTML 导出已移除；需要离线页面时可重新构建。

## 保留与清理

保留你修改后的分类栏 160px 宽度、文件夹区域宽度、场景结构、排列顺序及手机覆盖。已隐藏控件与其后代从新版布局树中移除，避免只在画布上看不见、仍占据图层树。仅手机端隐藏的项保持手机覆盖，不误删桌面内容。

重置返回这份清理后的设计基线，不返回最初那份包含旧导航、搜索框和侧栏的布局。

## 什么是原子控件

“原子”是一个可独立调整的界面元素，而不是单字或像素：

- 卡片：图标、类型、标题、摘要、标签、时间、字数、操作按钮分别是节点。
- 按钮：按钮本体是父节点，图标和文字是独立子节点。
- 来源：类型、标题、摘录、作者或角色、时间、定位与操作分别可选。
- 会话：头像、作者、时间、消息正文、消息操作、输入框、附件按钮、发送按钮分别可选。
- 正文：小标题、段落、引用、图片和说明分别可选。
- 输入框：输入框是一个原子控件，其占位文字、初始内容和样式在属性面板中编辑。
- 图片：整体作为一个原子控件，内部矢量路径不拆成界面控件。

父容器仍保留，可以整组移动、调整间距和排列。新增拆分出来的控件都有稳定 ID，导出后仍能准确对应。

## 调整与交接

1. 从场景选择器进入笔记库、阅读、编辑或问题共创。
2. 点击具体文字、图标或按钮子元素，或者通过图层树定位；使用搜索和折叠管理细层级。
3. 在属性面板中调整位置、文字、宽高、内外边距、字号、颜色、背景、边框、圆角、字重、行高和对齐。缺省字体和颜色可以继承父容器。
4. 手机属性单独覆盖；结构与顺序共用。删除父容器会连同其子控件一起删除，删除和复制均可撤销。
5. 写下需要后续实现的行为备注，使用“保存 HTML”或“导出 JSON”交接。

新版保存文件名带“原子布局”，以免与旧版导出混淆。HTML 包含当前配置与设计基线，下载后在新浏览器中也能继续调整。浏览器自动缓存不是磁盘备份，重要修改应及时另存文件。

输入、来源和会话为本地虚构样例，不连接模型或真实资料库。体验交互用于判断布局；已删除的侧栏不会通过体验按钮重新生成。
